# OptiGuard AI Frontend
# React-only frontend built 
## Pages included
1. Welcome Page
2. Auth Page (Sign Up / Login)
3. Dashboard
4. Diagnostics
5. AI Eye Scan
6. Results Overview
7. Test History
8. Screen Usage
9. Screen Health
10. AI Assistant
11. Donate / Support page

## Runs locally by
```bash
npm install
npm run dev
```
## Notes
-  For now, This is frontend-only and uses localStorage for mock login.
- Routing is already separated file-by-file.
